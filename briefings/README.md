# briefings/

Dated, human-readable analyst briefs (`BRIEF-YYYY-MM-DD.md`) produced by the
`/briefing` skill. Each brief's header states the date range it covers. The
machine-readable counterpart is `intelligence.json` at the repo root, which the
tracker's **Import briefing** button (Sleeve tab) reads into the ratification queue.

No user trading data ever lands here — briefs are built from public sources only.
